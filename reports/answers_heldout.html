A collection's membership can be specified in two ways: first, using target-based rules (relationship-mode) which include and exclude objects, and second, using an expression-based syntax to match objects (pattern-based collections or expression-mode). A collection's membership is specified in one of two ways. The first way uses target-based rules to specify which objects are included (and excluded) from the collection.
